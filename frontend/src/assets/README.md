# Assets Directory

This directory stores visual assets for the IIITDM Jabalpur Smart Hostel Portal.

## Background Image Replacement
To use an official campus photograph:
1. Place your photograph file here as `campus-bg.jpg` or `campus-bg.png`.
2. The stylesheets automatically reference this asset with a soft, readable institutional overlay.

## Institute Logo
If you have an official SVG/PNG logo of PDPM IIITDM Jabalpur, place it here as `iiitdmj-logo.svg` or `iiitdmj-logo.png`.
